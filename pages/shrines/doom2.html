To be able to play and mod Doom 2, you obviously need a copy of the game first.. However, it's a bit weird because, where with most games you just get the game, put mods in (and/or get a mod loader first), with doom and this setup all we really care about obtaining from the game are the data files called WADs.

WAD is a file extension that stands for Where's All the Data (or something like that lol). This is effectively just the assets, levels etc. for the game which would be loaded by the engine. There are two variants you might encounter; IWAD and PWAD:

  • IWADs are Internal WADs; these generally contain all the files the engine needs to play the game. Base levels, sounds, graphics etc.
  • PWADS are Patch WADs; these would have originally been how you modded the game by "patching" on extra content :D

Just know that if a source states something like "get an IWAD" or "put your IWAD in this folder", they mean the DOOM2.WAD (or equivelent..)

You just need to source the DOOM2.WAD file any way that suits you best. To my knowledge, if you buy the game off of steam/gog etc., you are able to go to the directory the game is installed and find the .WAD there :D

OR

You can download Freedoom; a free/libre set of assets for the game.

Why do we only care about an assets .WAD file? How do we play the game?

Well, that's where a source port comes in!

id Software actually released the source code to DOOM many moons ago lol so it's completely okay to just download and play the engine. It's just the assets that are proprietary :D and if we use something like freedoom then you can legitemately play modded doom absolutely free ><

Source Ports are the actual game engine we run. Although there are a variety of them, the only ones we care about for now are descendants of ZDoom.

The latest continuation of ZDoom is UZDoom. Up until recently, the main one was GZDoom but some shit happened and now the main fork is UZDoom. We pass our WADs and mods to UZDoom and boom we gaming!

A Source port gives us a bunch of benefits immediately like newer renderers such as Vulkan, mouse look and a bunch of other stuff. Even if you just ran UZDoom with DOOM.WAD, you'd already be having a considerably better (my opinion) time than just playing the original and we haven't even added any mods yet.

If you would like to try play DOOM2 with friends, there is also Zandronum. Along with it's variations, Zandronum is another ZDoom fork with an emphasis on multiplayer. Unfortunately, because it's a seperate fork of ZDoom, you have to find mods that explicitely support Zandronum to use in multiplayer. The site claims it supports old ZDoom and GZDoom mods so ig it's just more recent modifications to GZDoom means newer mods may or may not work for both so that's something you have to check on a per mod basis ^^

The recommended and latest fork of Zandronum is QZandronum.

I have a source port and an iwad, erm how do I play the game?

To play the game, the most basic setup you can have is to just put your IWADs in the same directory as the UZDoom executable, if you have mods, drag and drop them onto it, otherwise just run it.

However, there's a few problems with this..

  • What if we want multiple, specific sets of mods? Selecting the correct ones every time is annoying and error prone.
  • Our save games and config will default to one location and be shared among all mod lists.

ZDoom and it's predecessors can take command line parameters to specify all of these things. This means you can write very simple shell scripts for each of your mod lists/setups.

Shell

./uzdoom.exe -config "./Config.ini" -iwad "./DOOM2.WAD" -file "../path/to/mod.pk3" "../path/to/moremod.pk3" -savedir "../path/to/saves/"

...but that's annoying. I don't wanna write scripts, I wanna GAME.

That's where Launchers come in :3

Launchers allow you to select your iwad, mods and maps and generally save them as presets to swap between them at will. The command required to play will be created for you and you can just run the game from the launcher. Although there are a few of these, my favourite is Doom Runner.

Engine🚂

Next up is UZDoom. You can download this from ZDoom or Github.

Either way you will get a zip archive with the files. Unzip it and put it in the source_ports/zdoom/UZDoom-{version}/

Note the version part; The archive will come named with the version you downloaded. I suggest you keep it like that and don't replace older versions with newer ones. As I mentioned earlier, G/UZDoom are actually quite elaborate at this point and enable a lot of new features that modders can take advantage of but this does mean that I have ran into mod setups working for older versions and crashing if I use a newer version so I just keep a couple versions around. They're quite small so I think it's ok.

Run DoomRunner NOW!

There's a little bit of setup before we can actually start creating presets and playing. Don't worry about all the options yet.

At the top left, click "Menu" > "Initial Setup" and a dialog will pop up.

Under the Doom Engines, click the green (+) button and navigate to source_ports/zdoom/UZDoom-{version} and select the uzdoom executable to add it. It will have opened another dialog where you can name the engine and change it's options. We want to:

  • Add/make sure the version is in the name. This will help you distinguish between them later.
  • Change the "Config Directory" to source_ports/zdoom/configs
  • Change the "Data Directory" to source_ports/zdoom/data
  • Make sure the "Engine Family" is ZDoom

Once you've done that, click ok and it'll be added to the list :D Any time in the future you want to add another version, repeat this step, just adding a new entry.

The other steps in this dialog are pretty self explanatory.

  • "Directory with community maps" > browse to our "maps" folder.
  • (we don't have any maps yet but if we add the folder now and put them there they'll show up :D)
  • "Locate your IWADs" > browse to our "IWADS" folder and also check "Auto-update IWAD list from directory"

It's worth noting here, in the Engine and IWAD lists, you can right-click an entry and select "Set As Default" to have them be selected for every new preset :D But it only saves you a couple clicks so up to you.

and we're done with this dialog :D

One final thing before we can make any presets. The main UI has tabs along the top. Click "Data Directories" and on this page, check "Use preset name" for Save dir and Demo dir. This will keep your saves in separate folders named after the presets. This ensures your auto saves of other presets aren't overwritten when preset hopping. You could also check the box for the Screenshot dir to keep them organized by preset, but a good setup to make it easier to browse and backup your media is to have just the saves separate and specify a shared "media" folder with a subfolder for screens respectively.

Unfortunately, only checking the "Use preset name" box is mirrored across all presets. Specifying a path has to be done for each preset (at the time of writing this). To work around this, thankfully there is a way to specify global arguments that will be applied to all presets.

Navigate back to the "Files" tab, and at the bottom of the page, there are a couple text boxes to add "Additional arguments". Put the following in the one marked "[global]":

Shell

-shotdir "..\..\..\media\screenshots"

This way, all presets will put their screenshots in the same folder and we only have to specify it once.

If all the paths having a load of dots and slashes is confusing you, it's because all the paths used in the commands need to be either absolute (relative to the root of the drive) OR relative to where the engine executable is. If you've followed along, our uzdoom.exe is three folders deep from our top level DOOM2 folder where we've set everything up. Hence the three "..\" in the above flag. If you've deviated at all from my suggestions (which is totally fine), you might want to double check any relative paths are correct. ^^

Presets

The doom runner ui is pretty self-explainatory also but I'll walk through making a default "Vanilla" preset seeing how we don't have any mods or maps yet. The sections are numbered:

  1. Create Preset: Click the green (+) button and name it "Default" (or whatever you want). Make sure it's selected
  2. Select Engine: From the drop down, select the UZDoom we added.
  3. Select IWAD: Select DOOM2.WAD (or freedoom1.wad)
  4. Select map pack: You would pick a map here once you get some.
  5. Select Config: Navigate to your source_ports/zdoom/configs folder and create a file called Default.ini. I like to name these the same as the preset name to avoid confusion. It should show up here now. Everytime you make a new preset you could repeat this step to create a clean new config, however we'll set some basic defaults in the aptly name "Default" config and use the "copy config" button next to the drop down with this config selected and name it the new Preset to carry over these defaults. (that is if, shitty Windows would give it permission to create the files -.- try this, if it doesn't work ye just go to the folder and create a new one or copy the default and rename it..)
  6. Add mods: You would click the "add a mode file" or "add a directory with an extracted mod" and select as many mods as you want here (again, if we had any).

Now, you should be able to click "Launch" in the bottom right to play the game :D

Once the game launches, click once or press a key to bring up the menu and go to options. We don't need to change much from the UZDoom defaults but if we want to be efficient (lazy), we don't want to set things we care about every time so it's better to have this "bare minimum base". You can skip this if you don't care and just hit new game and rip and tear~ ><

  • Player Setup: Set your Name and change any of the other setting you care about here.
  • Sound Options: Get your levels right. The default on my setup is wayy too loud haha so ye it's very convenient setting this once. Might be worth getting in game to change these so you actually have continuous music to adjust.
  • Display Options: change any settings in here you want. There used to be more in here I'd change but the defaults became a bit better with UZDoom (looking at you texture filtering -.-) but ye some the settings aren't maxed in dynamic lights for example so look around in here.
  • Set Video Mode: here you can toggle fullscreen, set your max fps, vsync. At the bottom, choose a resolution preset or if your desired resolution isn't in there, set it manually then click "Apply Changes" with your desired windowed mode.

Anything else you'd want to change for specific use cases per preset.

Your settings will be saved to the config when you exit the game.

You may notice there are a variety of file types here, one of which I've even noted it could be zip or a folder (depending on how you get it). Well there is the original wad format; this the the PWADs I mentioned earlier. These are the original mod format if I'm not mistaken. However, UZDoom also supports loading .zip archives as well as folders so we can add those to doomrunner. But what about .pk3? These are actually the most common format you'll find doom2 mods in these days and you'd be forgiven for thinking this is some specific format because that was the point; .pk3 files are in fact literally renamed .zip files.. people started doing this long ago so that users weren't tempted or thought they had to extract their zipped mods and because .pk3 was originally from quake if I'm not mistaken, that guaranteed peoples archiving software wouldn't offer to open these :D and ye because compressed archives are just, well, compressed files and folders it needs no explaining that you can just add a directory containing an uncompressed mod and that will load all the same ^^

Now back in doom runner, under the "Add Mods" section, you can click the "add a mod file" or "add a directory with an extracted mod" buttons to add the mods obviously. But this list also dictates the load order of your mods which can matter.

As a rule of thumb, you want your main mod at the top (main generally being the mod that changes the most/what you're basing the list off of), then you want mods that add new content, gameplay and textures. After that you can put music and sounds. Then finally hud mods tend to be best last. We have so few mods here you could get away with any order probably but as you add more, you may run into problems.
